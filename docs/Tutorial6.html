Tutorial 6 Event Studies

An event study estimates how an outcome changes around a particular event. The key difficulty is not the before-and-after calculation itself, but constructing a credible prediction of what would have happened without the event.

In this tutorial, we begin with an example of stock-market abnormal returns, then move to regression-based interrupted time series using real monthly policy data.

By the end of this tutorial, you will be familiar with:

1 . Understanding event studies and constructing counterfactuals

2 . Estimating and interpreting abnormal returns in financial event studies

3 . Estimating level and trend changes using regression-based event studies

4 . Addressing autocorrelation and evaluating model robustness

5 . Extending event studies to multiple groups

Following the textbook, we use May–July 2015 as the estimation window to estimate normal returns, and August 6–24 as the event window to examine abnormal returns around the announcement.

A short window is often more defensible than a long window for financial announcements because more unrelated news can accumulate as time passes.

# Estimation window: May–July 2015
est_data <- google_stock %>%
  filter(Date >= "2015-05-01",
         Date <= "2015-07-31")

# Event window: August 6–24, 2015
event_data <- google_stock %>%
  filter(Date >= "2015-08-06",
         Date <= "2015-08-24")

Estimating three normal-return models

We will compare three approaches to estimating normal returns: Mean, Market, and Risk.

Mean-adjusted return: predict that Google would earn its average pre-event daily return, \(\widehat R_t=\overline R_{pre}\).

Market-adjusted return: predict that Google would earn the market’s return on that day, \(\widehat R_t=R_{m,t}\).

Risk-adjusted return: estimate \(R_t=\alpha+\beta R_{m,t}+\varepsilon_t\) in the estimation window, then use the model to predict what Google’s return would have been given the observed market return.

risk_model <- lm(Google_Return ~ SP500_Return, data = est_data)
summary(risk_model)

    AR_mean = Google_Return - expected_mean,
    AR_market = Google_Return - expected_market,
    AR_risk = Google_Return - expected_risk
  )

The abnormal returns are obtained by subtracting three different counterfactual predictions from the same observed return. We prefer an estimate that is robust to reasonable ways of predicting a normal return, although agreement across models is not proof that the announcement caused the difference.

Average and cumulative abnormal returns

The average abnormal return (\(AAR\)) and cumulative abnormal return (\(CAR\)) for an event window \(W\) are:

\[AAR_W=\frac{1}{|W|}\sum_{t\in W} AR_t, \qquad CAR_W=\sum_{t\in W} AR_t.\]

post_event <- event_data %>%
  filter(Date >= as.Date("2015-08-10")) %>%
  mutate(CAR_risk = cumsum(AR_risk))

post_event %>%
  summarise(
    days = n(),
    AAR_risk = mean(AR_risk),
    CAR_risk = sum(AR_risk)
  )
# A tibble: 1 × 3

1    11  0.00256   0.0281

We plot cumulative abnormal returns to examine how the estimated impact accumulates over time. While daily abnormal returns may return to zero after the announcement, CAR can remain positive even when daily abnormal returns return to zero, suggesting that the initial market reaction has not been reversed.

Sensitivity to the estimation window

The market-model estimates may depend on which pre-event observations are included. For example, the textbook discusses a large Google return in July 2015. Let’s refit the model without July to see whether the risk-adjusted event-day abnormal return changes.

short_est_data <- google_stock %>%
  filter(Date >= as.Date("2015-05-01"),
         Date <= as.Date("2015-06-30"))

market_model_early <- lm(Google_Return ~ SP500_Return,                      data = short_est_data)

obs_data <- event_data %>%
  mutate(AR_risk_early = Google_Return -      predict(market_model_early, newdata = event_data))

Regression-Based Event Studies: Interrupted Time Series

Introducing real policy data

Stock-market event studies are useful when we expect an abrupt response. Policies may instead produce a persistent effect on outcomes. We now analyze a classic interrupted time series (ITS) example using the real Seatbelts dataset available in base R.

Great Britain introduced compulsory front-seat seat-belt use on January 31, 1983. The dataset contains monthly observations from January 1969 through December 1984. The outcome drivers is the number of car drivers killed or seriously injured each month. Other variables include vehicle kilometers, petrol prices, and an indicator for the law being in effect.

Segmented regression model

A segmented regression separates an immediate level change from a change in slope:

\[ Y_t = \beta_0 + \beta_1 t^* + \beta_2 After_t + \beta_3(t^* \times After_t) + \varepsilon_t. \]

In the dataset, law switches to 1 in February 1983, the first complete month after the January 31 law took effect. We center time at that first coded intervention month. The interaction post_time is zero before the law and counts elapsed months afterward.

first_law_t <- which(seatbelt$law == 1)[1]
first_law_date <- seatbelt$date[first_law_t]

seatbelt <- seatbelt %>%
  mutate(
    time0 = t - first_law_t,
    after = law,
    post_time = time0 * after
  )

# Sanity Check
seatbelt %>%
  filter(abs(time0) <= 2) %>%
  select(date, drivers, time0, after, post_time)

Which model should we choose? The choice depends on our assumptions about the data-generating process. Road casualties may follow recurring seasonal patterns due to weather, daylight, and travel behavior. If these patterns exist, ignoring seasonality may lead us to mistakenly attribute seasonal fluctuations to the seat-belt law. Therefore, the seasonal model may provide a more credible estimate by accounting for these recurring patterns.

Visualizing effect size and confidence intervals over time

In a segmented regression, the estimated policy effect \(k\) months after the intervention is:

\[ \widehat\tau_k = \widehat\beta_2 + k\widehat\beta_3, \qquad k = 0, 1, 2, \ldots \]

The confidence interval depends on both coefficient variances and their covariance. For monthly data with possible serial correlation, we use a Newey–West HAC covariance matrix for the plot; the next section explains why. The lag = 12 choice is illustrative rather than universally optimal.

# Post-intervention months, starting with k = 0
post_effects <- seatbelt %>%
  filter(after == 1) %>%
  select(date, time0)

# HAC covariance matrix for the two relevant coefficients
V_hac <- sandwich::NeweyWest(its_season, lag = 12,prewhite = FALSE, adjust = TRUE)

b_level <- coef(its_season)["after"]
b_slope <- coef(its_season)["post_time"]

post_effects <- post_effects %>%
  mutate(
    effect = as.numeric(b_level + time0 * b_slope),
    se = sqrt(V_hac["after", "after"] +
              time0^2 * V_hac["post_time", "post_time"] +
              2 * time0 * V_hac["after", "post_time"]),
    lower = effect - 1.96 * se,
    upper = effect + 1.96 * se
  )

Statistical Inference and Robustness Checks

Autocorrelation and HAC

Monthly regression errors may be correlated with errors from nearby months. This is serial correlation. Ordinary OLS standard errors assume a simpler error-dependence structure than may be plausible for a time series.

First inspect the autocorrelation function of the residuals. Then compare conventional OLS inference with heteroskedasticity- and autocorrelation-consistent (HAC/Newey–West) inference.

The ACF plot shows substantial positive serial correlation in the regression residuals, particularly at shorter lags. This suggests that conventional OLS standard errors may be unreliable.

Compare the standard errors and p-values for after and post_time:

  • after (−300.67): The standard error decreases from 66.49 (OLS) to 39.61 (HAC). The immediate level change remains statistically significant.

  • post_time (+6.87): The standard error decreases from 4.85 (OLS) to 2.09 (HAC). The slope change becomes statistically significant (p = 0.158 under OLS versus p = 0.0012 under HAC).

Given the serial correlation in the residuals, HAC standard errors are more appropriate than conventional OLS standard errors, assuming the HAC specification is suitable. Notice that HAC does not necessarily increase standard errors; in this case, it reduces them for both coefficients.

However, HAC changes estimated uncertainty, not OLS coefficients. Its results can also depend on the selected bandwidth, which deserves sensitivity checks.

Most importantly, HAC cannot repair a biased counterfactual, omitted concurrent policy changes, or an inappropriate functional form. Correct statistical inference does not guarantee causal identification.

Sensitivity

Would the estimated level and slope changes survive alternative modeling choices? Here we (a) start the sample in 1975 instead of 1969 and (b) compare a specification without seasonal fixed effects. Both are simple specification checks rather than tests that prove identification.

its_recent <- lm(
  drivers ~ time0 + after + post_time + month,
  data = filter(seatbelt, date >= as.Date("1975-01-01"))
)

The two models controlling for seasonality produce relatively similar results, while excluding seasonality substantially changes both coefficients. This suggests that accounting for seasonal patterns is important for estimating the intervention’s effects.

Shortening the pre-law window may reduce the influence of historical structural changes, but it also provides fewer observations for estimating the baseline trend.

Overall, the direction of the estimated effects is consistent, but their magnitudes are sensitive to model specification, particularly seasonal adjustment.

Placebo

What if we pretend that a seat-belt law began in January 1980, before the actual law? To avoid contamination from the real intervention, use only observations before February 1983, then re-estimate the same segmented regression around the fake event date.

placebo_date <- as.Date("1980-01-01")

placebo_df <- seatbelt %>%
  filter(after == 0) %>%
  mutate(
    placebo_time0 = t - which(date >= placebo_date)[1],
    placebo_after = as.integer(date >= placebo_date),
    placebo_post_time = placebo_time0 * placebo_after
  )

placebo_model <- lm(
  drivers ~ placebo_time0 + placebo_after + placebo_post_time + month,
  data = placebo_df
)

lmtest::coeftest(
  placebo_model,
  vcov. = sandwich::NeweyWest(placebo_model, lag = 12, prewhite = FALSE, adjust = TRUE)

Conclusion

In this tutorial, we used a single-series event study to construct abnormal returns, then estimated policy-related level and slope changes with segmented regression. We translated those coefficients into dynamic estimated effects and 95% confidence intervals, assessed serial correlation using HAC standard errors, and checked the sensitivity of our results with alternative specifications and a fake intervention date. Finally, we examined how event-time coefficients can be plotted for multiple affected groups without introducing DID.

The central lesson is that estimation and statistical significance are not enough for causal identification. Each interpretation depends on whether the proposed no-event counterfactual is credible.
