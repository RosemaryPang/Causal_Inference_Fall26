Tutorial 6 Event Studies

An event study estimates how an outcome changes around a particular event. The key difficulty is not the before-and-after calculation itself, but constructing a credible prediction of what would have happened without the event.

In this tutorial, we begin with an example of stock-market abnormal returns, then move to regression-based interrupted time series using real monthly policy data.

By the end of this tutorial, you will be familiar with:

1 . Understanding event studies and constructing counterfactuals

2 . Estimating and interpreting abnormal returns in financial event studies

3 . Estimating level and trend changes using regression-based event studies

4 . Addressing autocorrelation and evaluating model robustness

5 . Extending event studies to multiple groups

Data preparation

  • Date: trading date.
  • Google_Return: Google’s daily stock return.
  • SP500_Return: daily S&P 500 return.

Following the textbook, we use May–July 2015 as the estimation window to estimate normal returns, and August 6–24 as the event window to examine abnormal returns around the announcement.

A short window is often more defensible than a long window for financial announcements because more unrelated news can accumulate as time passes.

# Estimation window: May–July 2015
est_data <- google_stock %>%
  filter(Date >= "2015-05-01",
         Date <= "2015-07-31")

# Event window: August 6–24, 2015
event_data <- google_stock %>%
  filter(Date >= "2015-08-06",
         Date <= "2015-08-24")

##Estimating three normal-return models

We will compare three approaches to estimating normal returns: Mean, Market, and Risk.

Mean-adjusted return: predict that Google would earn its average pre-event daily return, \(\widehat R_t=\overline R_{pre}\).

Market-adjusted return: predict that Google would earn the market’s return on that day, \(\widehat R_t=R_{m,t}\).

Risk-adjusted return: estimate \(R_t=\alpha+\beta R_{m,t}+\varepsilon_t\) in the estimation window, then use the model to predict what Google’s return would have been given the observed market return.

risk_model <- lm(Google_Return ~ SP500_Return, data = est_data)

event_data <- event_data %>%
  mutate(
    expected_mean = mean(est_data$Google_Return, na.rm = TRUE),
    expected_market = SP500_Return,
    expected_risk = predict(risk_model, newdata = event_data),
    AR_mean = Google_Return - expected_mean,
    AR_market = Google_Return - expected_market,
    AR_risk = Google_Return - expected_risk
  )

The abnormal returns are obtained by subtracting three different counterfactual predictions from the same observed return. We prefer an estimate that is robust to reasonable ways of predicting a normal return, although agreement across models is not proof that the announcement caused the difference.

event_data %>%
  select(Date, AR_mean, AR_market, AR_risk) %>%
  pivot_longer(cols = starts_with("AR_"),
               names_to = "method", values_to = "abnormal_return") %>%
  ggplot(aes(Date, abnormal_return, color = method)) +

Average and cumulative abnormal returns

The average abnormal return (\(AAR\)) and cumulative abnormal return (\(CAR\)) for an event window \(W\) are:

\[AAR_W=\frac{1}{|W|}\sum_{t\in W} AR_t, \qquad CAR_W=\sum_{t\in W} AR_t.\]

post_event <- event_data %>%
  filter(Date >= as.Date("2015-08-10")) %>%
  mutate(CAR_risk = cumsum(AR_risk))

post_event %>%
  summarise(
    days = n(),
    AAR_risk = mean(AR_risk),
    CAR_risk = sum(AR_risk)
  )
# A tibble: 1 × 3
   days AAR_risk CAR_risk
  <int>    <dbl>    <dbl>
1    11  0.00256   0.0281

We plot cumulative abnormal returns to examine how the estimated impact accumulates over time. While daily abnormal returns may return to zero after the announcement, CAR can remain positive even when daily abnormal returns return to zero, suggesting that the initial market reaction has not been reversed.

ggplot(post_event, aes(Date, CAR_risk)) +

Sensitivity to the estimation window

The market-model estimates may depend on which pre-event observations are included. For example, the textbook discusses a large Google return in July 2015. Let’s refit the model without July to see whether the risk-adjusted event-day abnormal return changes.

short_est_data <- google_stock %>%
  filter(Date >= as.Date("2015-05-01"),
         Date <= as.Date("2015-06-30"))

market_model_early <- lm(Google_Return ~ SP500_Return,                      data = short_est_data)

obs_data <- event_data %>%
  mutate(AR_risk_early = Google_Return -      predict(market_model_early, newdata = event_data))

obs_data %>%
  filter(Date > as.Date("2015-08-10")) %>%
  select(Date, AR_risk, AR_risk_early)

The results are highly consistent across the two estimation windows. On August 11, the estimated abnormal return is 5.35% using May–July data and 5.43% using May–June data, a difference of only 0.08 percentage points. The overall patterns are also similar across the two models, suggesting that our findings are robust to the choice of estimation window.
